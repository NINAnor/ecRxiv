# GPU X100 reference recovery

All 3759 included V1.1G objects match the recovered GPU V0.5 X100 lookup exactly (maximum difference 0.0 m). All 23 entries in the original SHA256SUMS.csv match, with no missing files. The package is preserved byte-for-byte, including original candidate-status metadata. That historical status is not rewritten to imply deployment approval; actual usage is established separately by the V1.1G script and delivered object values.

The delivered GPU calibration uses knot 1 m, lower slope 4.281660377624701 and upper slope 0.933252196706718. The prior QMD described CPU V0.4 slopes 3.7522924593 and 0.7369730202. Its reported CPU Pilot85 contract is not a validation of the GPU delivery; these variants must be identified separately.

The table-version gap is resolved. Original pilot/prediction data and environment are still required for reference regeneration, and X0 source-generation provenance remains unresolved. R bootstrap and Quarto rendering have not been rerun here.
